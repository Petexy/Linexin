Changelog

What changed in each Linexin release.

v2.1

Current linexin-2026-v2.1.4-x86_64.iso

Changes compared to the raw v2.0 ISO.

  • Added Linexin Hello — a welcome app that helps you finish setting up after installation.
  • Added an advanced installation option that enables the user to:
    • select which packages should be installed
    • select the bootloader manually
  • Added Kinexin Deco — a new, highly customizable window decoration for Kinexin Desktop.
  • Updated gtk-4.0 and gtk-3.0 settings to use Kinexin Deco style buttons for a unified UI.
  • Linexin Installer now fully supports lower resolutions (e.g. 800×600).
  • Linexin Installer now prevents the screen from going to sleep, which should eliminate problems when the user picks the wrong option for the GPU.
  • The system now uses bash as the default shell.
  • The Croatia wallpaper is now shown correctly in GNOME Settings.
  • Linexin Center has been updated to use server-side decorations on Plasma; customization options and a compact mode have been added.
  • DaVinci Installer and Affinity Installer are no longer included by default. They can be easily installed post-installation with Linexin Hello if needed.
  • Removed the Rounded Corners extension for GNOME due to instability, breakage after updates and memory leaks.
  • …and many other smaller or under-the-hood changes.

v2.0

Changes compared to the raw v1.1 ISO.

  • Kinexin Desktop, based on Plasma Desktop, has been added.
  • The installer now supports choosing between two desktop environments: Linexin Desktop (GNOME-based) and Kinexin Desktop (KDE Plasma-based).
  • Desktop Presets now support Kinexin Desktop with five themes:
    • Kinexin — Linexin Desktop-alike
    • 10ish — Windows 10-alike
    • 11ish — Windows 11-alike
    • 2worlds — a special theme, best for OLED screens
    • Plasmexin — a Breeze-based theme
  • The Linexin Installer has been modified: Disk Utility has been replaced with Partition Selection. Partitioning is now handled automatically by the installer, and managing existing partitions is done through GNOME Disks.
  • Linpama (Linexin Package Manager) has been added. It works as a pacman and AUR wrapper and allows installing packages from Linexin Center.
  • System Updater now supports updating AUR packages. It automatically reinstalls the kwin-effects present in Kinexin Desktop after kwin updates to maintain all functionality.
  • affinity-installer is now affinity-installer2: it supports Affinity Photo 2, Designer 2, Publisher 2 and Affinity (2025).
  • The DaVinci Installer tool has been fixed — the version in v1.1 no longer worked with the newest DaVinci Resolve.
  • The system has been fully separated from all its packages. All packages are now downloaded from linexin-repo when the ISO is built.
  • GNOME extensions moved from system-based to user-based, so they can be updated regularly.
  • Linexin Center now fully supports localization to any language.
  • Added new wallpapers.
  • …and many other smaller or under-the-hood changes.

v1.1

  • Added Linexin Center, which:
    • handles all Linexin-specific apps in one place
    • supports custom widgets written in Python (placed inside /usr/share/linexin/widgets/)
    • handles translations for every widget with a simple dictionary file
    • has a CLI option to run in single-widget mode (linexin-center -w [widget_filename])
    • prevents closing the app while a system command is running (e.g. pacman -Syu)
  • Linexin Updater is now integrated inside Linexin Center.
  • DaVinci Installer and Affinity Installer are now integrated inside Linexin Center.
  • Calamares has been deprecated — the new Linexin Installer replaces it as the system installer.
  • Linexin now fully automatically supports:
    • Legacy Boot (GRUB for both dual-boot and single-boot)
    • UEFI dual-boot for both Windows and other Linux (rEFInd)
    • UEFI single-boot (systemd-boot with timeout=0)
  • AppImageLauncher has been deprecated. The system now uses Gear Lever for handling AppImages.
  • Some Flatpaks are now installed if there's an internet connection during installation: Zen Browser, Bottles, Faugus Launcher, Heroic Launcher, Gear Lever.
  • Linexin should now support NVIDIA cards older than Turing (NV160/TUXXX), though this has not been tested extensively.
  • Added support for more languages: Chinese, French, German, Hindi, Polish, Portuguese, Russian, Spanish.
  • Fixed problems related to sound not playing through the minijack.
  • Added the linexin-sound-fix-usb-dac script in /bin for USB DACs with no sound below 30% volume (run with sudo).

For the complete history of changes, see the commit history on GitHub.
