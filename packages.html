What's Inside

The apps, desktops and drivers that ship on the Linexin ISO.

Pick your look

Choose one of two polished desktops during installation — and restyle either with one click.

  • Linexin Desktop Clean and modern — based on GNOME.
  • Kinexin Desktop Glassy and familiar — based on KDE Plasma.
  • Desktop Presets Four ready-made looks per desktop, switchable with one click.

Gaming out of the box

Sign in to your game store and play — no setup marathon.

  • Steam The biggest PC game store, preinstalled.
  • Wine Runs many Windows games and apps on Linux.
  • gamemode + gamescope Performance tools that can squeeze out extra FPS.
  • Heroic & Bottles Epic Games, GOG and more — added automatically when you install online.

Creative tools in a few clicks

Guided installers set up professional creative apps for you.

  • Affinity Installer Affinity Photo 2, Designer 2, Publisher 2 and Affinity (2025).
  • DaVinci Resolve Installer Professional video editing, used in real film studios.
  • Linexin Hello Offers both tools right after your first start.

Everyday essentials

The basics are ready the moment you log in.

  • Firefox Fast, private web browser.
  • Showtime Simple video player — every common format plays out of the box.
  • Flatpak & AppImage Install thousands of apps from the app store — AppImages work too.

Linexin's own apps

Everything important is point-and-click — no terminal needed.

  • Linexin Installer Installs the system in a few guided steps.
  • Linexin Hello Helps you finish setting up after installation.
  • Linexin Center Updates, apps and system tools in one place.
  • Linexin Updater Keeps the whole system up to date.

Solid under the hood

For the curious — the technology working behind the scenes.

  • Arch Linux Rolling release — always the newest software and drivers.
  • AMD · Intel · NVIDIA Graphics drivers ready on first boot.
  • PipeWire Modern, low-latency audio.
  • Timeshift System snapshots you can roll back to if anything goes wrong.

This is not the full list — for the complete package manifest, see packages.x86_64 on GitHub.
