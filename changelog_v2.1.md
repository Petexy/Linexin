Please be informed those changes applies when compared v2.1 to raw v2.0 ISO

- Added Linexin Hello
- Added advanced installation option that will enable user to:
    - select packages that should be installed
    - select Bootloader option manually
- Added Kinexin Deco - new, highly customizable Window Decoration for Kinexin Desktop
- Updated gtk-4.0 and gtk-3.0 settings to use Kinexin Deco style buttons for unification of UI
- Linexin Installer should now fully support lower resolutions (e.g. 800x600)
- Linexin Installer now prevents the screen from going to sleep, which should eliminate problems when the user picks wrong option for GPU
- System now uses bash for default shell
- Croatia wallpaper should now be shown on GNOME correctly in Settings
- Linexin Center has been updated to use Server-Side Decorations on Plasma as well as customization options and compact mode have been added to it
- DaVinci Installer and Affinity Installer are no longer included by default on the distro. They can be easily installed post-installation with Linexin Hello if needed.
- Removed Rounded Corners extension for GNOME due to instability, breakage after updates and memory leaks
...and many other smaller or under the hood changes
